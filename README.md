# BWC Exchange WebApp

### **PURPOSE**
I'd developed one WebApps for our  APOs' BWC Exchange Submission to reduce team's workload. The application includes:
- **𝐈𝐧𝐩𝐮𝐭:** Officer ID, BWC number, Battery percentage
- **𝐁𝐮𝐭𝐭𝐨𝐧:** Submit

### **OPERATION**

When press the submit button, the progam will check all of the format in text boxes.
- Officer ID must begin with PC, CPL, SGT or SSGT with ID  number
- BWC number must have 3 to 5 digits
- Battery level must between 0 and 100
- All fileds must be filled
Unless show the error message.

- Current date and time will be added automatically.
- Only one officer ID will be allowed to add to the Sheet, which means avoiding second time submission per day.
- This apps can be assessed from any devices such as; computer, ios and android os.

Unfortunately, officers are not allowed to use mobile phone during the shift. Therefore, my development was useless but I got an experience.
